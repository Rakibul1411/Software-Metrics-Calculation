AEEEM benchmark rows do not contain Java class identifiers, so they cannot be matched to extracted class predictions.
Why LC.csv cannot be used here

class is the defect label in AEEEM—it contains values such as buggy or clean. It is not a class-name column. LC also describes a fixed historical Lucene dataset, not the current Lucene repository you extracted.

For a valid AEEEM accuracy test, use Model evaluation below: upload labelled AEEEM source datasets, upload LC.csv or LC.arff as the labelled target, and keep the label column as class.
